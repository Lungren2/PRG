# Aseza's original Delete and Summary source

Aseza Patiwe wrote the original Delete and Summary project. These four files are unchanged copies from `DeleteUserInterface/DeleteUserInterface`, also imported in commit `a718eb51255279cbd4a8a6dc3ae318711014808c` under `src/DeleteUserInterface`.

- `frmDelete.cs` handles selection, confirmation, record removal, and opening Summary.
- `frmSummaryReport.cs` calculates totals, averages, and five status counts, then displays and saves the report.
- The two `.Designer.cs` files define the original grid, buttons, and `rtbSummary` control.

These files are reference material, outside the compiled app. Original formatting and bugs are retained for an accurate comparison. Open **Aseza Delete and Summary source** in `PRG272.sln` to compare them in Visual Studio.

See [the current code map](../../docs/delete-summary.md) for the adapted methods and integration changes.
